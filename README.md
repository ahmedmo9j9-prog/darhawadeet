# نظام إدارة دار حواديت — النسخة التشغيلية

هذه النسخة مبنية لتعمل كـ Web App متعدد الأجهزة باستخدام GitHub Pages للواجهة وSupabase كقاعدة بيانات سحابية مشتركة.

## المزايا
- تسجيل دخول حقيقي عبر Supabase Auth مع اسم مستخدم وكلمة مرور.
- صلاحيات: مدير، كاشير، أمين مخزن، محاسب.
- قاعدة بيانات موحدة للكتب والمخزون والمبيعات والمستخدمين.
- إضافة/تعديل كل بيانات الكتاب.
- استيراد Excel مع دعم أعمدة «الكتاب» و«اسم الكتاب» و«العنوان» وغيرها.
- مخازن متعددة ومعارض.
- كاشير وفواتير وخصومات ونقدي/فيزا/آجل.
- خصم المخزون تلقائيًا عند البيع داخل Transaction واحدة.
- تقارير مبيعات وأكثر الكتب مبيعًا ومخزون منخفض ومستحقات المؤلفين.
- إعادة طباعة الفاتورة، وتصميم 80mm للطابعة الحرارية.
- حسابات المؤلفين والأمانة وأوامر الطباعة.
- لوجو دار حواديت داخل الواجهة والفاتورة.

## التشغيل
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor وشغّل ملف `schema.sql` كاملًا.
3. أنشئ أول مستخدم من Authentication > Users، ثم اجعل دوره Manager في SQL:

```sql
update public.user_profiles
set username='admin', full_name='مدير النظام', role='manager', active=true
where email='EMAIL_OF_YOUR_FIRST_USER';
```

4. افتح الموقع أول مرة، واضغط «إعداد الاتصال»، ثم أدخل Project URL وPublishable/anon Key.
5. بعدها سجل الدخول بـ admin وكلمة المرور التي أنشأتها في Supabase.
6. من «المستخدمون» أضف باقي الحسابات.

مهم: في إعدادات Supabase Authentication، عطّل Confirm email إن كنت تريد أن ينشئ المدير حسابات المستخدمين وتعمل فورًا دون انتظار تأكيد البريد.

## GitHub Pages
ارفع `index.html`, `styles.css`, `app.js`, `schema.sql`, `README.md`, `logo.jpg` إلى المستودع. ثم فعّل GitHub Pages من Settings > Pages.

## الأمان
- استخدم Publishable/anon Key في الواجهة فقط.
- لا تضع Service Role Key داخل GitHub أو المتصفح.
- RLS مفعل على الجداول، والبيع وتعديل المخزون يتم عبر RPC آمن.

## المضاف في هذا الإصدار — المالية والعهدة
- صفحة **المصروفات والنفقات** لتسجيل البنود والمبالغ وطريقة الدفع والمخزن والمستفيد والبيان.
- تصدير المصروفات إلى Excel.
- صفحة **العهدة** لعرض أرصدة العهد لكل مستخدم.
- صرف عهدة جديدة.
- تسوية/رد العهدة مع منع التسوية بأكبر من الرصيد الحالي.
- ظهور إجمالي مصروفات اليوم ورصيد العهد في لوحة التحكم.
- ظهور إجمالي المصروفات وصافي النقد والعهد القائمة في التقارير.

بعد استبدال ملفات المشروع، يجب تشغيل **كل ملف schema.sql** في Supabase SQL Editor حتى تُنشأ جداول المصروفات والعهد ودوالها وصلاحياتها.
