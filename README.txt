# نظام دار حواديت — النسخة النهائية الموحدة

تشمل هذه النسخة كل التعديلات المطلوبة:
- تسجيل دخول + مستخدمين متعددين وصلاحيات.
- Dashboard.
- كاشير POS.
- حفظ الفواتير وربطها بالتقارير.
- خصومات + نقدي/فيزا/آجل.
- خصم المخزون بعد البيع.
- طباعة الفاتورة وإعادة طباعتها بصيغة حرارية 80mm.
- إدارة الكتب.
- تعديل كل بيانات الكتاب.
- تعديل الأسعار والكميات.
- استيراد الكتب من Excel مع التعرف على "الكتاب" و"اسم الكتاب" والمسافات الزائدة.
- حماية من الكتابة فوق كتالوج غير فارغ بقائمة فارغة، وترحيل مفاتيح التخزين القديمة.
- نسخة احتياطية لقائمة الكتب من شاشة الكتب.
- المؤلفون، الأمانة، الطباعة، المعارض، التقارير.
- شعار دار حواديت مضاف للواجهة والفاتورة.
